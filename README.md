# AI学生 · 教育预测引擎（AI STUDENT）

> **本仓库 = AI学生 v4 / v4.1「修炼版」**（在 v3 雏形之上加入九字秘法修炼体系与教材投喂）。
> 早期版本见 [ai-student](https://github.com/jacklore123/ai-student)（v3 雏形），
> 批量解题工具见 [ai-student-nine-words](https://github.com/jacklore123/ai-student-nine-words)。

一套 **单文件自包含** 的 Windows 桌面程序（Tkinter 深色界面），把「一个虚拟学生
从 6 岁到 18 岁（K12，4380 天）的认知成长」做成**可模拟、可规划、可对话、可被
摄像头观测、可记录成学习轨迹**的系统。

> v3 核心升级：在原有「学生状态模拟器」之上，新增 **学习轨迹系统**
> （SkillState / ErrorRecord / LearningEpisode），让 4380 天真正产生结构化学习事件。

> v4 核心升级：**物理学习修炼化**。九字秘法（删·解·秒·分·合·列·推·创·造）各有
> 独立修为与段位，榜样模型划分为四重境界（启蒙→立榜→分科→精进），并把学情
> 量化为「相当于榜样几岁的水平 + 榜位」的统一评价标准。

> v4.1 核心升级：**教材投喂**。把真正的课本与练习丢进来，程序自己读、自己切分
> （章→节→知识点→习题），然后按真实内容顺序**自动学习**，并把学生视角的
> 思考过程一路写出来（读题→删→解/分/合/列→复盘纠错）。图片/扫描页走视觉模型。

## 核心思想（发明专利思想）

- 0–100 岁学习者模型 → 取 6–18 岁 K12 子集（4380 天）。
- 「空白学生体」剥离具体知识、保留认知规律。
- 「榜样模型知识库」作为成长终点（牛顿 / 高斯 / 居里）。
- S 型成长曲线 + 双时间轴（实际年龄 ↔ 榜样等效年龄）。
- MCTS + UCB 学习路径规划；时间压缩算法秒级模拟 4380 天。
- 九字秘法：把物理学习的九步思维（删解秒分合列推创造）做成可修炼、可记账的招式。
- 统一量度：不以分数计量而以水平计量，用榜样等效年龄与榜位衡量所有学生。

## 功能特性

- 6–18 岁 / 4380 天成长模拟、`StudentState` 认知维度、注意力 / 疲劳 / 记忆。
- MCTS 路径规划、榜样成长曲线、双时间轴动态纠偏。
- v3 学习轨迹系统：技能掌握度、错误 / 认知误区、学习事件闭环。
- v4 修炼体系：九字秘法独立修为、四重境界与突破、榜位（境界内 0–100）。
- v4.1 教材投喂：课本/练习 → 知识地图 → 自动学习（含学生视角思考过程）。
- 摄像头采集与录制、上传视频 → 双模型（本地 + 外部）分析 → 生成档案。
- 本地 Ollama（默认 `deepseek-r1:7b`）+ 外部 OpenAI 兼容 API（DeepSeek / OpenAI /
  Kimi / 通义 / 智谱 / 阿里云百炼等）。
- JSON / CSV / JSONL 数据仓库、逐日 Word / Markdown / JSON 档案、训练语料生成。
- `--selftest` / `--smoke` / `--test-video` 命令行自检与冒烟测试。

## 九字秘法 · 境界 · 榜位（v4 核心）

### 九字秘法（点一格 = 修炼一式）

| 字 | 名 | 释义 | 侧重 |
| --- | --- | --- | --- |
| 删 | 图像化拆解 | 文字转图像，转完一句删一句 | 感知 · 建模 |
| 解 | 方程求解 | 方程解的思维，例如必修一的知三求二 | 规则 · 推理 |
| 秒 | 二级结论速判 | 结合常见的二级结论，秒杀适合的题 | 推理 · 直觉 |
| 分 | 隔离受力 | 受力分析 + 正交分解 + 隔离法（分析有几个接触点，每一点都可能有力） | 建模 · 推理 |
| 合 | 整体简力 | 整体法，简化受力 | 建模 · 规则 |
| 列 | 坐标列式 | 按照坐标系列出平衡状态方程 | 规则 · 建模 |
| 推 | 公式体系推导 | 对课本的公式进行记忆编程，以图像化的去推导出所有的公式体系 | 规则 · 推理 · 直觉 |
| 创 | 模型演化 | 高中 108 个物理模型，在脑海里演化这些模型，进行理想化模拟 | 建模 · 直觉 |
| 造 | 动手造物 | 动手做物理实体，去改变世界 | 感知 · 直觉 |

每式都有独立的 **修为（0–100%）** 与段位（初窥 / 小成 / 大成 / 圆满），
记在 `数据集/skill_states.json`（subject 为「秘法」），与知识点的掌握度互不混淆。

### 四重境界与突破

| 境界 | 年龄 | 要务 |
| --- | --- | --- |
| 🌱 启蒙境 | 0–6 岁 | 培养想象力与专注力（模拟区间之前，作为起点前史） |
| 🌿 立榜境 | 6–12 岁 | 引入榜样模型，把焦虑换成超越前人的动力 |
| 🌳 分科境 | 12–15 岁 | 选择学科方向，学习该学科的规则 |
| 🏛 精进境 | 15–18 岁 | 发展学科专长，与历史科学家的进度条实时比对 |

修为越过境界门槛时会触发「突破」事件。**实际境界**（按年龄）与
**水平境界**（按榜样等效年龄）分开计算，两者之差就是"越境/待追"的级数。

### 统一评价标准（榜位）

打开工具栏「🀄 修炼 · 九字秘法」即可看到：

- 修为值、实际境界、水平境界、段位、榜位（境界内 0–100）；
- 「你的水平 ≈ ai牛顿 X 岁 Y 天」，以及距 K12 顶点还剩多少天；
- 九字秘法九宫格（各式的修为与段位）、当前境界要务；
- 榜样时间轴：已达成的里程碑与下一个目标；
- 「创」式当前应演化的物理模型。

评价结果会落盘到 `数据集/level_rating.json`，也可从窗口导出，作为统一量度
喂给大模型或用于横向比较（`rank_global` 为跨境界的全局榜位）。

## 教材投喂 · 自动学习（v4.1）

把真正的课本与练习丢进来，程序会自己读、自己切、自己学。

### 用法

界面：工具栏 **「📚 教材投喂」** → 选课本/练习所在文件夹（或单个文件）→
程序扫描切分并装载，随后按课本顺序自动学习，思考区实时显示学生的思考过程；
再点一次按钮即暂停。菜单「数据 → 📚 教材投喂 · 自动学习…」同样入口。

命令行（适合批量与验证）：

```bash
python ai学生_v4.py --ingest "F:\高中物理课本\物理必修一课本.pdf" --study 10
python ai学生_v4.py --ingest "练习册文件夹" --out "教材语料"     # 只建地图不学习
```

### 支持的输入

| 格式 | 读取方式 |
| --- | --- |
| `.txt` / `.md` | 直接读（自动尝试 utf-8/gbk） |
| `.docx` | 解压读 `word/document.xml`（零依赖） |
| `.pdf` | pypdf 提取文字层；无文字层（扫描版）→ 渲染页面后走视觉模型 |
| `.png/.jpg/...` | 视觉模型「看课本」转写（本地 Ollama 视觉或外部视觉接口） |

### 切分规则（自动处理教材排版）

- 识别 `第X章 / 第X节 / 1.1` 三级结构，并**过滤每页重复的页眉**；
- 过滤封面、目录行（带页码）、图注、页码等非正文内容；
- 把中文硬换行粘回自然段，段落即「知识点」；
- 只在 `练习与应用 / 复习与提高 / 问题与练习 / 课后练习` 栏目内切题，
  且**题号必须连续**才认作题目（避免把实验步骤、编号列表当题）；
- 清理内容过少的空壳章节。

### 自动学习时学生"在想什么"

每个学习日都会输出一条完整思考链，例如：

```text
📖 读题: 一物体做匀加速直线运动, 初速度 2 m/s …
🔎 划关键词: 速度、加速度、位移 | 初判题型: 计算 | 该练的字: 解
🀄 删: 把题干一句一句转成图与量, 转完的句子从脑子里删掉; 抄出已知: v0=2 m/s …
🎯 要问的是: 6 s 末的速度；6 s 内的位移
🀄 顺手过一遍「列·坐标列式」: 建系→投影→逐轴列方程 …
🧭 本题路线: 解→列 → 动笔
✗ 卡住了: calc —— 计算过程粗心出错
🔁 纠正: 放慢步骤、逐行验算
✓ 重试后做出来了: 掌握 12%→19%
📈 修为 0.31/5 · 🌿立榜境·小成 · 榜位 41/100 · 等效 ai牛顿 8岁96天
```

真实题干会写进学习事件（`learning_episodes.jsonl` 的 `question` 字段，
形如「【教材题】…」），秘法修为与榜位同步更新；知识地图落盘为
`数据集/material_map.json`，可复用、可对比、可作为教育数据。

### 视觉模型（必须，已留好接口）

「像真人一样看书」需要视觉模型：图片与扫描页由视觉模型转写后再进入同一切分与
学习流程。当前实现已接通两条通道：

1. 外部 OpenAI 兼容视觉接口（`设置 → API密钥 → 地址/密钥/模型`），
   模型名含 `vl / vision / gpt-4o / qwen-vl` 等即判定为视觉模型；
2. 本地 Ollama 视觉模型（如 `llava`、`qwen2.5-vl`）。

都不可用时自动降级为跳过并在备注里说明，不会中断学习流程。
后续可继续扩展：PDF 页面直接渲染（poppler / PyMuPDF）、公式与图形的结构化识别、
把"看懂一道题的图"作为独立的学习事件记录。

## 快速开始

### 1. 安装依赖

```bash
# 建议 Python 3.10–3.12（3.14 打包 Tcl/Tk 需额外处理，见下文）
pip install -r requirements.txt
```

核心依赖：`numpy`、`opencv-python`、`Pillow`、`python-docx`；`tkinter` 为 Windows
自带标准库。摄像头、图像、Word 依赖缺失时程序会自动降级，不影响主功能。

### 2. 运行

```bash
python ai学生_v4.py                    # 启动图形界面
python ai学生_v4.py --selftest         # 逻辑自检（无窗口）
python ai学生_v4.py --smoke            # GUI 冒烟测试
python ai学生_v4.py --test-video "视频路径"   # 命令行跑完整视频分析链路
```

### 3. 配置与数据位置

- 配置自动保存到 `%USERPROFILE%\.ai_student_config.json`（删除不影响运行）。
- 运行时数据仓库默认在 `C:\ai_student_data`（无写权限时回退
  `%USERPROFILE%\ai_student_data`）。
- 本目录下的 `ai学生_数据仓库/` 为导出的数据归档，可随仓库提交或按需整理。

## 大模型接口

- 本地 Ollama：默认 `http://127.0.0.1:11434`，默认模型 `deepseek-r1:7b`，支持视觉。
- 外部 OpenAI 兼容 API：DeepSeek / OpenAI / Kimi / 通义 / 智谱 / 阿里云百炼等，
  300s 超时 + 3 次重试 + 密钥脱敏。
- 视觉模型自动判定；不支持时自动降级为「画面统计 + 文本」。

## 打包为 exe

```bash
python -m PyInstaller --onefile --windowed --name "ai学生_v4" ai学生_v4.py
```

> 注意：Python 3.14 会把 Tcl/Tk 脚本库打包为 `libtcl9.0.4.zip` / `libtk9.0.4.zip`，
> 直接运行时 `_tkinter` 找不到 `init.tcl`。打包前需先解压这两个 zip，并在打包命令中
> 设置 `TCL_LIBRARY` 与 `TK_LIBRARY` 指向解压出的 `tcl_library` / `tk_library`。

成品 `.exe` 已由 `.gitignore` 排除（二进制、体积大、难做版本 diff）。建议上传到
GitHub Releases，见下文。

## 关于数据仓库与隐私

- 本仓库默认只提交**文本数据**（`.json` / `.md` / `.csv` / `.jsonl` / `.txt`）。
  `.docx`、`.xlsx`、`.mp4`、`.exe` 等二进制已由 `.gitignore` 忽略（可由程序通过
  「📚 4380 天档案」「上传视频」等功能重新生成）。
- `ai学生_数据仓库/数据集/` 中的逐日档案为匿名化编号（如 `D04381_12岁1天`），
  不含真实姓名。
- **请勿提交**任何包含真实人脸、会议、姓名、联系方式等个人隐私的视频 / 文件到公开仓库。

## 如何上传到 GitHub

### 方式 A：网页上传（最简单）

1. 在 GitHub 新建仓库（`New repository`），可设为 Private 或 Public。
2. 把本目录（`F:\ai学生雏形\`）里的文件直接拖到仓库页面，或点
   `Add file → Upload files`。
3. 填写提交说明后点 `Commit changes`。

### 方式 B：命令行（推荐，保留 Git 历史）

```bash
cd F:\ai学生雏形
git init
git add .
git commit -m "Initial commit: AI学生 v3"

# 若中文文件名显示为转义，可让状态更可读（可选）：
git config core.quotepath false

git branch -M main
git remote add origin https://github.com/你的用户名/你的仓库名.git
git push -u origin main
```

首次推送会要求登录 GitHub；建议使用 Personal Access Token（PAT）或 GitHub CLI：

```bash
gh auth login
gh repo create 你的仓库名 --public --source=. --remote=origin --push
```

### 发布 exe（可选）

1. 本地打包得到 `ai学生_v4.exe`。
2. 仓库页面点 `Releases → Create a new release`。
3. 把 `.exe` 作为附件上传，这样下载者无需安装 Python。
