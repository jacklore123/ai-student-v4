【读题】物体从 P 点（xP = 3 m）运动到 Q 点（xQ = -2 m），求位移大小、方向，并画出位置坐标与位移矢量。

【删】
- 图 1.2-10：一维坐标轴，P 在 +3 m 处，Q 在 -2 m 处 → 画数轴，标 P(3)、Q(-2)。
- "从 P 点运动到 Q 点" → 初位置 x1 = 3 m，末位置 x2 = -2 m。
- "位移大小是多少" → 求 |Δx|。
- "方向如何" → 求 Δx 的符号，判断沿 x 轴正/负方向。
- "画出位置坐标和位移矢量" → 数轴上标点 + 带箭头线段由 P 指向 Q。
- 删完。

【解】
已知量：x1 = 3 m，x2 = -2 m；未知量：位移 Δx 及其大小、方向。
运动学五个量中本题只涉及位置与位移，属"知二求一"：
Δx = x2 - x1 = -2 m - 3 m = -5 m。
大小 |Δx| = 5 m；负号表示方向沿 x 轴负方向。

【秒】
二级结论：一维直线运动中，位移等于末位置坐标减初位置坐标，Δx = x末 - x初，其绝对值即位移大小，符号即方向。
适用条件：必须在同一坐标轴上取定正方向后使用；本题正方向已由坐标轴给定（向右为正）。命中，可秒判 Δx = -5 m。

【分】
略（本题为运动学描述，不涉及受力分析）。

【合】
略（无多物体、无内力外力问题）。

【列】
建一维坐标系：原点 O 在 0 处，正方向沿 x 轴向右。
按轴列式：Δx = xQ - xP = (-2 m) - (3 m) = -5 m。
未知数 1 个（Δx），方程 1 个，个数对齐。

【推】
从位移定义式推：位移是位置的变化量，Δx = x末 - x初。
代入：Δx = -2 m - 3 m = -5 m。
大小取绝对值：|Δx| = 5 m。
方向由符号判定：Δx < 0，故位移方向与正方向相反，即沿 x 轴负方向（由 P 指向 Q，向左）。

【创】
模型：一维质点直线运动模型。理想化过程：把物体视为质点，忽略其形状大小，只保留位置坐标；物体沿 x 轴由 x = 3 m 处移动到 x = -2 m 处，净位置变化为向左 5 m。注意路程与位移不同：若物体直接由 P 到 Q，路程也是 5 m；若中途往返，路程会大于 5 m，但位移仍为 -5 m。

【造】
动手方案：
器材：米尺（或卷尺）、粉笔、地面。
步骤：在地上画一条直线作 x 轴，标出原点 0、正方向箭头、刻度；在 +3 m 处标 P，在 -2 m 处标 Q；用粉笔从 P 到 Q 画一带箭头线段。
预期现象：箭头由 P 指向 Q，指向刻度减小的一侧，长度对应 5 m，直观验证位移大小为 5 m、方向沿 x 轴负方向。

【答案】
位移大小：5 m；
方向：沿 x 轴负方向（由 P 点指向 Q 点，即向左）。
位置坐标与位移矢量图：在 x 轴上标出 P(3 m)、Q(-2 m)，用带箭头的有向线段由 P 指向 Q 表示位移矢量，箭头向左，线段长度表示 5 m。

【自检】
量纲：Δx 单位为 m，与坐标单位一致，正确。
方向：Δx = -5 m < 0，方向沿 x 轴负方向，与"由 P 指向 Q"一致，正确。
设问完整性：已回答位移大小（5 m）、方向（沿 x 轴负方向），并说明画法，三个设问全部作答。
易错点提醒：位移大小是 5 m 而非 -5 m，负号只表示方向，不表示大小。
