### Q001 第一章 运动的描述

**题目**: 如图 1.2-10，一个物体从 P 点运动到 Q 点，坐标 xP 为3 m，xQ 为－ 2 m，它的位移大小 是多少？方向如何？请你画出它的位置坐标和 位移矢量。

- 用了: 删解秒列推创造 (7 个)
- 答案: 位移大小：5 m； 方向：沿 x 轴负方向（由 P 点指向 Q 点，即向左）。 位置坐标与位移矢量图：在 x 轴上标出 P(3 m)、Q(-2 m)，用带箭头的有向线段由 P 指向 Q 表示位移矢量，箭头向左，线段长度表示 5 m。

**【删】** - 图 1.2-10：一维坐标轴，P 在 +3 m 处，Q 在 -2 m 处 → 画数轴，标 P(3)、Q(-2)。 - "从 P 点运动到 Q 点" → 初位置 x1 = 3 m，末位置 x2 = -2 m。 - "位移大小是多少" → 求 |Δx|。 - "方向如何" → 求 Δx 的符号，判断沿 x 轴正/负方向。 - "画出位置坐标和位移矢量" → 数轴上标点 + 带箭头线段由 P 指向 Q。 - 删完。

**【解】** 已知量：x1 = 3 m，x2 = -2 m；未知量：位移 Δx 及其大小、方向。 运动学五个量中本题只涉及位置与位移，属"知二求一"： Δx = x2 - x1 = -2 m - 3 m = -5 m。 大小 |Δx| = 5 m；负号表示方向沿 x 轴负方向。

**【秒】** 二级结论：一维直线运动中，位移等于末位置坐标减初位置坐标，Δx = x末 - x初，其绝对值即位移大小，符号即方向。 适用条件：必须在同一坐标轴上取定正方向后使用；本题正方向已由坐标轴给定（向右为正）。命中，可秒判 Δx = -5 m。

**【列】** 建一维坐标系：原点 O 在 0 处，正方向沿 x 轴向右。 按轴列式：Δx = xQ - xP = (-2 m) - (3 m) = -5 m。 未知数 1 个（Δx），方程 1 个，个数对齐。

**【推】** 从位移定义式推：位移是位置的变化量，Δx = x末 - x初。 代入：Δx = -2 m - 3 m = -5 m。 大小取绝对值：|Δx| = 5 m。 方向由符号判定：Δx < 0，故位移方向与正方向相反，即沿 x 轴负方向（由 P 指向 Q，向左）。

**【创】** 模型：一维质点直线运动模型。理想化过程：把物体视为质点，忽略其形状大小，只保留位置坐标；物体沿 x 轴由 x = 3 m 处移动到 x = -2 m 处，净位置变化为向左 5 m。注意路程与位移不同：若物体直接由 P 到 Q，路程也是 5 m；若中途往返，路程会大于 5 m，但位移仍为 -5 m。

**【造】** 动手方案： 器材：米尺（或卷尺）、粉笔、地面。 步骤：在地上画一条直线作 x 轴，标出原点 0、正方向箭头、刻度；在 +3 m 处标 P，在 -2 m 处标 Q；用粉笔从 P 到 Q 画一带箭头线段。 预期现象：箭头由 P 指向 Q，指向刻度减小的一侧，长度对应 5 m，直观验证位移大小为 5 m、方向沿 x 轴负方向。

### Q003 第一章 运动的描述

**题目**: 从高出地面 3 m 的位置竖直 向上抛出一个小球，它上升 5 m 后回 落，最后到达地面（图 1.2-12）。 分 别以地面和抛出点为原点建立一维坐 标系，方向均以向上为正，填写以下 表格。 21 位置变化快慢的描述——速度3 生活和科学研究中经常需要知道物体运动的 快慢和方向，你还记得初中是怎样描述物体运动 快慢的吗？运动员在比赛中的不同时段，运动的 快慢一样吗？ 问题 速度 不同的运动，位置变…

- 用了: 删解列推创造 (6 个)
- 答案: 以地面为原点、向上为正： 抛出点坐标：+3 m； 最高点坐标：+8 m； 落地点坐标：0 m。 以抛出点为原点、向上为正： 抛出点坐标：0 m； 最高点坐标：+5 m； 落地点坐标：-3 m。

**【删】** - 图/符号：一维竖直坐标轴，正方向向上。 - 已知量：抛出点离地高度 h0 = 3 m；小球上升最大高度相对抛出点 Δh = 5 m；最终落地点为地面。 - 关键点：抛出点 A、最高点 B、落地点 C。 - 以地面为原点 O1：抛出点坐标 x_A1 = +3 m；最高点坐标 x_B1 = 3 m + 5 m = +8 m；落地点坐标 x_C1 = 0 m。 - 以抛出点为原点 O2：抛出点坐标 x_A2 = 0 m；最高点坐标 x_B…

**【解】** 本题不涉及运动学五个量求速度/加速度，只做坐标系中位置坐标的换算。 设向上为正。 以地面为原点：x_A1 = +3 m，x_B1 = +8 m，x_C1 = 0 m。 以抛出点为原点：x_A2 = 0 m，x_B2 = +5 m，x_C2 = -3 m。 两套坐标关系：x_2 = x_1 - 3 m。

**【列】** 一维坐标轴列式： 地面原点：x_1(A)=3 m，x_1(B)=3+5=8 m，x_1(C)=0 m。 抛出点原点：x_2(A)=0 m，x_2(B)=5 m，x_2(C)=0-3=-3 m。 未知数与方程个数对齐：三个关键点坐标均由已知高度直接确定。

**【推】** 坐标定义：位置坐标 = 从原点到该点沿正方向的有向距离。 以地面为原点，向上为正，则抛出点在原点上方 3 m，故 x=+3 m；最高点在抛出点上方 5 m，故 x=+8 m；地面点就是原点，故 x=0 m。 以抛出点为原点，向上为正，则抛出点 x=0 m；最高点在其上方 5 m，故 x=+5 m；地面在其下方 3 m，故 x=-3 m。

**【创】** 模型：竖直上抛的“点模型”，只关心位置坐标，不关心速度、加速度和时间。 理想化过程：小球视为质点；只取抛出点、最高点、落地点三个状态点；坐标轴方向向上为正。

**【造】** 可动手验证：在墙上贴一张竖直纸条，标出地面、抛出点、最高点。用米尺量出地面到抛出点 3 m、抛出点到最高点 5 m。分别以地面和抛出点为 0 刻度，向上读数为正，向下读数为负，即可读出上述坐标。
