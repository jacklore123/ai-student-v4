【读题】小球从高出地面 3 m 处竖直上抛，上升 5 m 后回落至地面；分别以地面和抛出点为原点（向上为正）建立一维坐标系，填写位置坐标表格。

【删】
- 图：竖直方向一维运动，抛出点离地 3 m，最高点在抛出点上方 5 m。
- 关键点三个：抛出点 A、最高点 B、落地点 C（地面）。
- 已知量：抛出点高度 h0 = 3 m（相对地面）；上升高度 Δh = 5 m。
- 坐标系 1：原点在地面，向上为正 → 地面 x = 0，抛出点 x = +3 m，最高点 x = +8 m。
- 坐标系 2：原点在抛出点，向上为正 → 抛出点 x = 0，最高点 x = +5 m，地面 x = −3 m。
- 问：各关键点在两坐标系中的坐标。

【解】
设向上为正方向。
坐标系一（原点 O₁ 在地面）：
- 地面：x₁ = 0
- 抛出点：x₁ = +3 m
- 最高点：x₁ = 3 + 5 = +8 m
- 落地点（地面）：x₁ = 0

坐标系二（原点 O₂ 在抛出点）：
- 抛出点：x₂ = 0
- 最高点：x₂ = +5 m
- 地面（落地点）：x₂ = −3 m

【秒】略（本题为坐标建立与读数，无运动学二级结论可秒判）。

【分】略（本题不涉及受力分析）。

【合】略（本题不涉及整体法与隔离法）。

【列】一维坐标轴：x = 各点到原点的有向距离，向上为正。
- 坐标系一：x₁(地面)=0，x₁(抛出点)=+3 m，x₁(最高点)=+8 m。
- 坐标系二：x₂(抛出点)=0，x₂(最高点)=+5 m，x₂(地面)=−3 m。
未知数 3 个位置 × 2 个坐标系 = 6 个坐标值，方程 6 个（每个位置由原点定义直接给出），未知数与方程个数对齐。

【推】坐标定义式：x = 位置 − 原点位置（沿正方向取正）。
- 坐标系一：原点在地面，故 x = 离地高度，向上为正。
- 坐标系二：原点在抛出点，故 x = 相对抛出点的竖直位移，向上为正；地面在抛出点下方 3 m，故为 −3 m。
两坐标系间关系：x₁ = x₂ + 3 m，验证：最高点 5+3=8 ✓，地面 −3+3=0 ✓。

【创】模型：质点竖直上抛的“位置—坐标”模型。理想化过程：把小球视为质点，只关心它经过抛出点、最高点、地面三个位置的坐标，不涉及速度与时间。脑中演化：从抛出点出发向上 5 m 到最高点，再下落 8 m 回到地面；换原点只是把整条数轴平移，各点相对间距不变。

【造】动手验证方案：取一根 8 m 长的竖直标尺（或墙面贴刻度纸），在离地 3 m 处做标记 A（抛出点），在离地 8 m 处做标记 B（最高点），地面为 C。分别以 C 和 A 为零刻度贴两条纸带，读出 A、B、C 在两条纸带上的读数，即可验证：地面系读数为 3、8、0，抛出点系读数为 0、5、−3。预期现象：两条纸带读数相差恒为 3 m。

【答案】
以地面为原点（向上为正）：地面 x = 0；抛出点 x = +3 m；最高点 x = +8 m；落地点 x = 0。
以抛出点为原点（向上为正）：抛出点 x = 0；最高点 x = +5 m；地面（落地点）x = −3 m。

【自检】
- 量纲：各坐标均为长度，单位 m，正确。
- 方向：向上为正，地面在抛出点下方故取负值 −3 m，方向标注正确。
- 是否回答全部设问：题目要求填两套坐标系下各位置坐标，已全部给出。
- 一致性检验：x₁ = x₂ + 3 m 对三个位置均成立，自洽。
