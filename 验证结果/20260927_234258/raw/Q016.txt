【读题】运动员从 5 m 跳台双脚朝下自由落下，两张连续照片中双脚离水面高度分别为 3.4 m 和 1.8 m，求手机连拍时间间隔。

【删】
- 跳台高度 H = 5 m，运动员双脚朝下自由落下 → 初速度 v0 = 0，加速度 a = g（取 10 m/s²），竖直向下。
- 第一张照片：双脚离水面 h1 = 3.4 m → 下落位移 x1 = H − h1 = 5 − 3.4 = 1.6 m。
- 第二张照片：双脚离水面 h2 = 1.8 m → 下落位移 x2 = H − h2 = 5 − 1.8 = 3.2 m。
- 两张照片连续 → 时间间隔 Δt 即为所求。
- 图像化：一条竖直向下的数轴，原点在跳台，x1 = 1.6 m 处为第一张，x2 = 3.2 m 处为第二张，两点间时间差 Δt。

【解】
已知量：v0 = 0，a = g = 10 m/s²，x1 = 1.6 m，x2 = 3.2 m。
未知量：Δt。
运动学五个量（v0、v、a、x、t）中，对第一张照片：知 v0、a、x1，可求 t1；对第二张照片：知 v0、a、x2，可求 t2。则 Δt = t2 − t1。知三求二，方程数足够。

【秒】
二级结论：初速度为零的匀加速直线运动，位移与时间平方成正比，x = (1/2)gt²，即 t = √(2x/g)。
适用条件：v0 = 0，加速度恒定，从静止开始计时。本题运动员自由落下，初速度为零，满足条件，可直接用。

【分】
略（本题为单个质点的自由落体运动，不涉及多个物体接触与受力分析）。

【合】
略（无整体法与隔离法之需）。

【列】
取竖直向下为正方向，原点在跳台。
对第一张照片：x1 = (1/2)g t1²
对第二张照片：x2 = (1/2)g t2²
所求：Δt = t2 − t1
未知数 t1、t2、Δt 共 3 个，方程 3 个，个数对齐。

【推】
由母公式 x = v0 t + (1/2)a t²，代入 v0 = 0、a = g：
x = (1/2)g t²
解得 t = √(2x/g)。
t1 = √(2 × 1.6 / 10) = √0.32 ≈ 0.5657 s
t2 = √(2 × 3.2 / 10) = √0.64 = 0.8 s
Δt = t2 − t1 = 0.8 − 0.5657 ≈ 0.234 s

【创】
模型：自由落体模型（初速度为零、加速度为 g 的匀加速直线运动）。
理想化演化：运动员从静止开始下落，忽略空气阻力，双脚位置即运动员下落位移的末端；两张照片对应两个时刻的下落位移，时间差即连拍间隔。整个过程可视为质点沿竖直方向的匀加速直线运动。

【造】
动手验证方案：
器材：小球、米尺、手机（连拍模式）、支架。
步骤：
1. 将手机固定，开启连拍，对准竖直下落的区域。
2. 让小球从某一高度自由落下，同时连拍。
3. 从照片中读出小球在两个连续时刻的位置，量出下落位移 x1、x2。
4. 用 t = √(2x/g) 算出两时刻，求差得连拍间隔。
预期现象：算出的间隔与手机标称连拍间隔接近，验证公式正确。

【答案】
Δt ≈ 0.23 s（约 0.2 s）。

【自检】
- 量纲：√(m / (m/s²)) = √(s²) = s，正确。
- 方向：自由落体竖直向下，位移取向下为正，时间间隔为标量，无方向问题。
- 是否回答全部设问：题目只问连拍时间间隔，已求出 Δt ≈ 0.23 s，回答完整。
- 数值合理性：0.23 s 与手机连拍间隔量级相符，合理。
