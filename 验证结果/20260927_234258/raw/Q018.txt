【读题】题干给出频闪照片（每隔 0.04 s 闪光一次）及小球自由下落时各闪光时刻的位置（数字为落下的距离，单位 cm），问可用哪几种方法测量自由落体加速度并试算。

【删】
- 图：小球自由下落，频闪照片，相邻闪光时间间隔 T = 0.04 s。
- 量：照片中数字 = 小球落下的距离，单位 cm（即从下落起点算起的位移）。
- 问：通过这幅照片测重力加速度 g 的方法有哪几种，并试一试。
- 题目信息不足：题干未给出照片中具体数字（各闪光时刻的位移数值），因此无法代入具体数值计算 g。需要补充：照片中各次闪光对应的下落距离（cm）读数，或至少相邻两闪光间的位移差。

【解】
已知量：T = 0.04 s（相邻闪光时间间隔）。
未知量：g。
运动学五量：v0 = 0（自由落体初速为零）、a = g、t = nT、x（位移）、v。
知三求二：只要从照片读出位移 x 与对应时间 t，即可求 g。
可用方法（均基于匀变速直线运动规律）：
1. 逐差法：由 Δx = aT²，取相邻相等时间间隔的位移差，求 a = Δx/T²。
2. 位移公式法：由 x = (1/2)gt²，取某闪光时刻的 x 与 t = nT，求 g = 2x/t²。
3. 速度—时间图像法：由 v_n = x_{n+1} - x_{n-1} / (2T) 求各时刻速度，作 v–t 图，斜率即 g。
4. 平均速度法：中间时刻速度等于该段平均速度，v_mid = x/t，再结合 v = gt 求 g。

【秒】
二级结论：匀变速直线运动中，连续相等时间间隔 T 内的位移差为恒量 Δx = aT²。
适用条件：初速度任意、加速度恒定、时间间隔必须相等。
自由落体满足 a = g 且 v0 = 0，故可直接用 Δx = gT² 秒判 g = Δx/T²。
注意：必须用照片中相邻相等时间间隔的位移差，不能跨间隔乱用。

【分】
略（本题为运动学测量问题，不涉及多物体受力隔离）。

【合】
略（无整体法与隔离法需求）。

【列】
建立一维坐标：取竖直向下为正方向，起点为小球释放点。
设第 n 个闪光时刻 t_n = nT，对应下落距离 x_n。
方程一（位移公式）：x_n = (1/2)g(nT)²。
方程二（逐差关系）：x_{n+1} - 2x_n + x_{n-1} = gT²，或相邻位移差 Δx = gT²。
方程三（速度公式）：v_n = g nT，且 v_n = (x_{n+1} - x_{n-1})/(2T)。
未知数 g 与方程个数对齐：只要读出至少两组 (x, t) 或三个连续 x，即可解出 g。

【推】
母公式：匀变速直线运动位移公式 x = v0 t + (1/2)a t²。
自由落体 v0 = 0，故 x = (1/2)g t²。
对相邻两个相等时间间隔 T：
x_n = (1/2)g(nT)²，x_{n-1} = (1/2)g[(n-1)T]²。
相减：x_n - x_{n-1} = (1/2)gT²(2n-1)。
再对相邻位移差作差：Δx = (x_{n+1} - x_n) - (x_n - x_{n-1}) = gT²。
故 g = Δx/T²。
速度公式由 v = v0 + at 推得 v_n = g nT；又由平均速度等于中间时刻速度推得 v_n = (x_{n+1} - x_{n-1})/(2T)。

【创】
模型：自由落体 = 初速为零、加速度为 g 的匀加速直线运动。
理想化过程：忽略空气阻力，小球仅受重力，频闪时间间隔严格相等，照片读数准确。
脑中演化：小球越落越快，相邻闪光间位移越来越大，且位移差恒定，这正是匀变速直线运动的特征。

【造】
动手验证方案：
器材：小球、刻度尺、频闪光源（或手机连拍/慢动作摄像）、背景标尺。
步骤：
1. 让小球自由下落，用频闪光源每隔 0.04 s 闪光一次，拍摄照片。
2. 在照片上读出各闪光时刻小球的下落距离 x_n（cm），换算为 m。
3. 计算相邻位移差 Δx，用 g = Δx/T² 求 g。
4. 也可作 v–t 图，求斜率得 g。
预期现象：Δx 基本恒定，g 约为 9.8 m/s²（考虑误差）。

【答案】
测量自由落体加速度的方法有：
1. 逐差法：g = Δx/T²，其中 Δx 为相邻相等时间间隔 T = 0.04 s 内的位移差。
2. 位移公式法：g = 2x/t²，t = nT。
3. 速度—时间图像法：由 v_n = (x_{n+1} - x_{n-1})/(2T) 求各时刻速度，作 v–t 图，斜率即 g。
4. 平均速度法：v_mid = x/t，结合 v = gt 求 g。
由于题目未给出照片中具体数字，无法算出 g 的数值。题目信息不足：需要照片中各闪光时刻的下落距离读数（单位 cm），才能代入计算。若补充数据，按上述任一方法即可求出 g，方向竖直向下，单位 m/s²。

量纲：Δx/T² 为 m/s²，正确；2x/t² 为 m/s²，正确。
