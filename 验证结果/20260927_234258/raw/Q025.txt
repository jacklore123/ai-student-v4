【读题】初速度为 0、加速度为 a 的匀加速直线运动，要求证明前 n 秒位移比、第 n 秒内位移比、以及连续相等时间间隔 T 内位移差恒为 aT²。

【删】
- 初速度 v0 = 0，加速度 a（常量），匀加速直线运动。
- 前 1 s、前 2 s、前 3 s……位移：x1, x2, x3, …（从 t=0 起累计到 t=1,2,3,… 的位移）。
- 第 1 s 内、第 2 s 内、第 3 s 内……位移：xI, xII, xIII, …（各 1 s 区间内的位移）。
- 连续相等时间间隔 T 内位移：s1, s2, s3, …, sn（每段时长均为 T）。
- 待证：(1) x1:x2:x3:… = 1:4:9:…；(2) xI:xII:xIII:… = 1:3:5:…；(3) Δs = s2−s1 = s3−s2 = … = sn−sn−1 = aT²。

【解】
核心方程只有一个：x = v0 t + (1/2) a t²，本题 v0 = 0，故 x = (1/2) a t²。
(1) 令 t = 1, 2, 3, …（单位 s）：x1 = a/2，x2 = 2a，x3 = 9a/2，… 即 x_n = (1/2) a n²，比值 1:4:9:…。
(2) 第 n 秒内位移 = 前 n 秒位移 − 前 (n−1) 秒位移：x_n − x_{n−1} = (1/2)a n² − (1/2)a(n−1)² = (1/2)a(2n−1)，取 n=1,2,3,… 得 a/2, 3a/2, 5a/2, …，比值 1:3:5:…。
(3) 设第 n 段起点时刻 t_{n−1} = (n−1)T，终点 t_n = nT，则 s_n = (1/2)a(nT)² − (1/2)a[(n−1)T]² = (1/2)aT²(2n−1)。相邻差 s_n − s_{n−1} = (1/2)aT²[(2n−1) − (2n−3)] = aT²，与 n 无关，故各差相等。

【秒】
命中二级结论：初速为零的匀加速直线运动，
- 前 n 个相等时间末的位移比 1:4:9:…（适用条件：v0 = 0，a 恒定）；
- 各连续相等时间段内位移比 1:3:5:…（适用条件：v0 = 0，a 恒定，时间段等长）；
- 连续相等时间间隔内位移差 Δs = aT²（适用条件：匀变速，a 恒定，T 相等；对 v0 是否为零无要求）。
本题三问恰好全部命中，可直接秒判，但仍需给出推导以证明。

【分】
略（本题为纯运动学证明，不涉及受力分析）。

【合】
略（无多物体、无内力外力问题）。

【列】
取一维坐标轴沿运动方向，原点取 t=0 位置，正方向与 a 同向。
基本方程：x(t) = v0 t + (1/2) a t²，本题 v0 = 0。
未知量：x_n、x_n − x_{n−1}、s_n − s_{n−1}；方程个数与未知量一一对应，可解。

【推】
从母公式 v = v0 + at 与 x = v0 t + (1/2)at² 出发：
- 消去 t 得 v² − v0² = 2ax（备用，本题不用）。
- 令 v0 = 0，得 x = (1/2)at²，由此推出 (1)(2)。
- 对任意两时刻 t1、t2，位移差 Δx = (1/2)a(t2² − t1²) = (1/2)a(t2−t1)(t2+t1)；取 t2 − t1 = T，t1 = (n−1)T，t2 = nT，得 Δx = aT²(n − 1/2)，相邻两段相减即得 aT²，推出 (3)。

【创】
模型：质点从静止出发的匀加速直线运动（如光滑斜面上由静止释放的小车、自由落体）。
理想化演化：t=0 时 v=0，位置 x=0；随 t 增大，v 线性增大，x 按 t² 增长；把时间轴切成等长小段 T，每段位移依次为 aT²/2, 3aT²/2, 5aT²/2, …，呈等差数列，公差 aT²。

【造】
可动手验证方案：
器材：长直轨道（或斜面）、小车、打点计时器（或光电门）、纸带、刻度尺。
步骤：让小车从静止开始做匀加速运动，用打点计时器每隔 T = 0.02 s 打一点；量出各连续相等时间间隔内的位移 s1, s2, s3, …；计算 s2−s1, s3−s2, …，看是否近似相等且等于 aT²（a 由纸带求出）。
预期现象：各差值在误差范围内相等，且比值 s1:s2:s3 ≈ 1:3:5。

【答案】
(1) x1:x2:x3:… = 1:4:9:…（由 x = (1/2)at²，t = 1,2,3,… 得 x_n ∝ n²）。
(2) xI:xII:xIII:… = 1:3:5:…（第 n 秒内位移 = (1/2)a(2n−1)，n = 1,2,3,…）。
(3) Δs = s2 − s1 = s3 − s2 = … = sn − sn−1 = aT²（方向沿加速度方向，大小为 aT²）。

【自检】
- 量纲：x 单位为 m，aT² 单位为 m/s²·s² = m，量纲一致。
- 方向：位移差沿加速度方向，本题一维运动，方向由 a 的正负决定。
- 设问覆盖：三问全部证明，且均给出适用条件（v0 = 0、a 恒定、T 相等）。
- 无信息不足问题，题目条件完整。
