### Q004 第一章 运动的描述

**题目**: 关于位移和路程，下列四位同学的说法 是否正确？如果不正确，错在哪里？ 同学甲：位移和路程在大小上总相等，只 是位移有方向，是矢量，路程无方向，是标量。 同学乙：位移用来描述直线运动，路程用 来描述曲线运动。 同学丙：位移是矢量，它取决于物体的始 末位置；路程是标量，它取决于物体实际通过 的路线。 同学丁：其实，位移和路程是一回事。

- 用了: 删解秒推创造 (6 个)
- 答案: 甲：不正确。位移大小与路程不是总相等；只有单向直线运动时二者大小才相等，其余情况路程大于位移大小。甲说“位移有方向、路程无方向”这部分正确。 乙：不正确。位移和路程都可描述直线运动和曲线运动，区别不在运动轨迹形状，而在“是否只由始末位置决定…

**【删】** - 甲：位移大小 = 路程大小，总相等；位移有方向（矢量），路程无方向（标量）。 - 乙：位移 → 描述直线运动；路程 → 描述曲线运动。 - 丙：位移是矢量，取决于始末位置；路程是标量，取决于实际通过的路线。 - 丁：位移和路程是一回事。 - 问：四说法是否正确？错在哪？

**【解】** 本题为概念辨析题，不涉及运动学公式求解，无需“知三求二”。 核心判据只有两条： 1. 位移：从初位置指向末位置的有向线段，矢量，大小 = 初末位置直线距离，方向由初指向末。 2. 路程：物体运动轨迹的实际长度，标量，只有大小。 二者关系：一般情况下路程 ≥ 位移大小；只有单向直线运动时路程 = 位移大小。

**【秒】** 二级结论：路程 ≥ |位移|，等号仅当单向直线运动时成立。 适用条件：任何运动都满足“路程不小于位移大小”；等号条件必须是“单向直线运动”，不能推广到往返直线或曲线运动。

**【推】** 从定义出发推导二者关系： - 位移由初、末位置唯一确定，与路径无关； - 路程沿轨迹累加，与路径有关； - 若轨迹为曲线或往返直线，实际路径长度必大于初末位置直线距离，故路程 > 位移大小； - 若轨迹为单向直线，路径长度恰等于初末位置距离，故路程 = 位移大小。 因此“总相等”不成立。

**【创】** 模型演化：把运动想象成从 A 到 B 的两种走法—— ① 沿直线从 A 走到 B：路程 = AB，位移大小 = AB，方向 A→B； ② 沿曲线从 A 到 B：路程 > AB，位移大小仍 = AB，方向仍 A→B。 再演化成 A→B→A 往返：位移 = 0，路程 = 2AB，直接推翻“总相等”和“是一回事”。

**【造】** 动手验证方案： 器材：绳子一段、米尺。 步骤：在桌上标 A、B 两点。 ① 绳子拉直从 A 到 B，量绳长 = 路程，量 AB 直线距离 = 位移大小，二者相等； ② 绳子绕曲线从 A 到 B，再量绳长与 AB 距离，发现绳长 > AB； ③ 绳子从 A 到 B 再回到 A，绳长为 2AB，而位移为 0。 预期现象：路程 ≥ 位移大小，往返时位移可为 0 而路程不为 0。

### Q006 第一章 运动的描述

**题目**: 在台球比赛中，某球以 1.5 m/s 的速度垂 直撞击边框后，以 1.3 m/s 的速度反向弹回，球 与边框接触的时间 Δt 为0.08 s，求该撞击过程 中球的加速度。

- 用了: 删解秒列推创造 (7 个)
- 答案: 加速度大小为 35 m/s²，方向与初速度方向相反（即由边框指向球弹回的方向）。

**【删】** - 图：球 → 边框，垂直入射；碰后反向弹回。 - 已知量：初速度大小 v0 = 1.5 m/s，方向指向边框；末速度大小 v = 1.3 m/s，方向背离边框；时间 Δt = 0.08 s。 - 未知量：加速度 a（大小和方向）。 - 关键：速度反向，必须先规定正方向。

**【解】** 规定初速度方向为正方向。 则 v0 = +1.5 m/s，v = -1.3 m/s。 a = (v - v0) / Δt = (-1.3 - 1.5) / 0.08 = -2.8 / 0.08 = -35 m/s²。 负号表示加速度方向与初速度方向相反，即由边框指向球弹回的方向。

**【秒】** 适用条件：匀变速直线运动，加速度恒定。 本题接触时间短，可近似视为匀变速，直接用 a = Δv / Δt 秒判。 Δv = -2.8 m/s，Δt = 0.08 s，a = -35 m/s²。

**【列】** 沿初速度方向建一维坐标轴，取初速度方向为正。 方程：a = (v - v0) / Δt。 未知数 a 一个，方程一个，个数对齐。

**【推】** 由加速度定义式：a = Δv / Δt = (v - v0) / Δt。 代入：a = (-1.3 - 1.5) / 0.08 = -35 m/s²。 方向：与初速度方向相反。

**【创】** 模型：匀变速直线运动模型。 理想化过程：球与边框接触的 0.08 s 内，速度由 +1.5 m/s 均匀变为 -1.3 m/s，加速度恒定，方向始终与初速度相反。

### Q015 第二章 匀变速直线运动的研究

**题目**: 把一张纸片和一块橡皮同时释放下落， 哪个落得快？再把纸片捏成一个很紧的小纸团， 和橡皮同时释放，下落快慢有什么变化？怎样 解释这个现象？

- 用了: 删解秒分合列推创造 (9 个)
- 答案: 第一次：橡皮落得快，纸片落得慢。 第二次：纸片捏成紧纸团后，下落明显变快，会接近橡皮的下落快慢；若纸团足够紧、足够小，理想情况下可与橡皮几乎同时落地。 解释：真空中所有物体自由落体加速度均为 g，应同时落地；实际空气中，纸片展开时迎风面积大…

**【删】** - 对象1：一张纸片，形状“展开”，面积大，空气阻力作用显著。 - 对象2：一块橡皮，体积小、密度大，空气阻力相对重力很小。 - 操作1：纸片与橡皮同时释放下落，比较落地快慢。 - 操作2：把纸片捏成很紧的小纸团，再与橡皮同时释放，比较落地快慢变化。 - 问：哪个落得快？变化是什么？为什么？ - 图像化：空气中两个物体从同一高度由静止释放；纸片像“受阻力很大的薄片”，橡皮像“近似只受重力的重物”；纸团像“空气阻力显著减小的小重物”。

**【解】** 设下落高度为 h，初速度 v0=0。若忽略空气阻力，则 h = (1/2)gt^2，t = sqrt(2h/g)。 此时纸片、橡皮、纸团下落时间相同，应同时落地。 但实际有空气阻力。空气阻力与物体形状、迎风面积、速度等有关。纸片展开时迎风面积大，空气阻力相对重力不能忽略，甚至可与重力接近，因此加速度小于 g，下落慢；橡皮空气阻力相对重力很小，近似自由落体，下落快。 纸片捏成紧纸团后，迎风面积大大减小，空气阻力显著减小，其运动更接近自由落…

**【秒】** 二级结论：在真空中，所有物体自由落体加速度都为 g，与质量、材料无关，同时落地。 适用条件：忽略空气阻力，只受重力。 本题中空气阻力不可忽略，所以不能直接套“同时落地”；只能说明橡皮更接近该理想情况，纸片展开时偏离最大，纸团居中。

**【分】** 对下落物体隔离受力： - 重力 G=mg，方向竖直向下。 - 空气阻力 f，方向竖直向上，大小随迎风面积和速度增大而增大。 - 合力 F合=mg-f，方向向下。 纸片展开：f 较大，F合=mg-f 较小，a=F合/m=g-f/m 较小。 橡皮：f 很小，a≈g。 纸团：f 比展开纸片小很多，a 比展开纸片大，接近 g。

**【合】** 整体法不适用，因为纸片、橡皮、纸团不是同一连接体，应分别隔离分析。 共同点是都受重力向下、空气阻力向上；差别在空气阻力相对重力的大小。 因此比较快慢的关键不是“谁重谁轻”单独决定，而是“空气阻力相对重力是否可忽略”。

**【列】** 取竖直向下为正方向。 对任一物体： mg - f = ma a = g - f/m 下落高度 h 时，若近似匀加速： h = (1/2)at^2 t = sqrt(2h/a) 可见 a 越大，t 越小，下落越快。 纸片展开：f 大，a 小，t 大，下落慢。 橡皮：f 小，a≈g，t 小，下落快。 纸团：f 比展开纸片小，a 比展开纸片大，t 比展开纸片小，下落变快，接近橡皮。

**【推】** 从母公式推： 牛顿第二定律：F合=ma。 竖直方向：F合=mg-f。 所以 a=(mg-f)/m=g-f/m。 运动学：v0=0，h=(1/2)at^2，得 t=sqrt(2h/a)。 因此空气阻力 f 越大，a 越小，t 越大，下落越慢。 纸片捏成纸团后，形状变紧，迎风面积减小，同高度、同速度附近 f 减小，所以 a 增大，t 减小，下落变快。

**【创】** 模型：空气中落体模型。 理想化演化： 1. 若完全没有空气阻力，纸片、橡皮、纸团都做自由落体，a=g，同时落地。 2. 若有空气阻力，纸片展开时阻力大，运动偏离自由落体最大，下落最慢。 3. 纸片捏成纸团后，阻力减小，运动向自由落体靠近，下落变快。 4. 橡皮因阻力相对重力很小，始终最接近自由落体。 所以现象本质是：空气阻力对轻而面积大的物体影响大，对重而面积小的物体影响小。

**【造】** 可动手验证： 器材：一张纸、一块橡皮、秒表或手机慢动作拍摄、米尺。 步骤： 1. 从同一高度同时释放展开纸片和橡皮，观察并记录落地先后。 2. 把同一张纸捏成很紧的小纸团，再从同一高度与橡皮同时释放，观察落地先后。 3. 可再用慢动作视频比较落地时间差。 预期现象： 第一次橡皮明显先落地，纸片后落地； 第二次纸团与橡皮落地时间差明显变小，甚至很接近。 结论：空气阻力使展开纸片下落变慢；捏成纸团后空气阻力减小，下落变快。

### Q016 第二章 匀变速直线运动的研究

**题目**: 跳水运动员训练时从 5 m 跳台双脚朝下 自由落下，某同学利用手机的连拍功能，连拍 了多张照片。测得其中两张连续的照片中运动员 双脚离水面的高度分别为3.4 m和1.8 m。由此估 算手机连拍时间间隔是多少？

**【删】** - 跳台高度 H = 5 m，运动员双脚朝下自由落下 → 初速度 v0 = 0，加速度 a = g（取 10 m/s²），竖直向下。 - 第一张照片：双脚离水面 h1 = 3.4 m → 下落位移 x1 = H − h1 = 5 − 3.4 = 1.6 m。 - 第二张照片：双脚离水面 h2 = 1.8 m → 下落位移 x2 = H − h2 = 5 − 1.8 = 3.2 m。 - 两张照片连续 → 时间间隔 Δt 即为所求。 - …

**【解】** 已知量：v0 = 0，a = g = 10 m/s²，x1 = 1.6 m，x2 = 3.2 m。 未知量：Δt。 运动学五个量（v0、v、a、x、t）中，对第一张照片：知 v0、a、x1，可求 t1；对第二张照片：知 v0、a、x2，可求 t2。则 Δt = t2 − t1。知三求二，方程数足够。

**【秒】** 二级结论：初速度为零的匀加速直线运动，位移与时间平方成正比，x = (1/2)gt²，即 t = √(2x/g)。 适用条件：v0 = 0，加速度恒定，从静止开始计时。本题运动员自由落下，初速度为零，满足条件，可直接用。

**【列】** 取竖直向下为正方向，原点在跳台。 对第一张照片：x1 = (1/2)g t1² 对第二张照片：x2 = (1/2)g t2² 所求：Δt = t2 − t1 未知数 t1、t2、Δt 共 3 个，方程 3 个，个数对齐。
